# カードバトルゲーム 説明書

このゲームは、山札から引いたカードを使って相手のHPを0にすることを目指す、1対1のターン制カードバトルです。デッキは8種類あり、それぞれ全く異なる戦い方ができます。

---

## 1. ゲームルール

### 基本の流れ
1. 対戦開始時にデッキを選び、初期手札（3枚）を受け取ります。
2. 先攻・後攻を決めて対戦がスタートします。
3. 自分のターンでは、手札の**メインカード**を1枚だけメインフィールドに出す（使用する）か、**サブカード**を好きな枚数サブフィールドに出すことができます。
4. **メインカードを出すとターンが終了**します（1ターンに使えるメインは1枚まで）。サブカードは何枚出してもターンは終わりません。
5. 相手のHPを0にすれば勝利、自分のHPが0になれば敗北です。

### メインカードとサブカード
- **メインカード**：即座に効果が発動し、使い終わると墓地へ送られます（ダメージを与える／回復する／カードを引くなど、その場限りの効果）。
- **サブカード**：サブフィールドに置いておくことで効果を発揮するカードです。多くは「Nターン継続」という形で、置かれている間毎ターン効果が発動し続けます。継続ターンが終わると自動的に墓地へ送られます。
- サブフィールドに置けるカードの枚数には上限があります（通常3枚、「キング」デッキは6枚）。上限に達した状態で新しいサブカードを出すには、既存のサブカードを墓地へ送って空きを作る必要があります。

### 手札・山札・墓地
- 手札の上限は**7枚**です。
- 山札がなくなると、墓地のカードがシャッフルされて山札に戻ります（リサイクル）。
- 手札のカードは墓地ゾーンにドラッグ＆ドロップすることで自分から捨てることもできます（1ターンに捨てられる枚数には上限があり、デッキによって異なります）。

### HP
- 初期HPは**20,000**（デッキ効果でボーナスが付く場合あり）。
- 画面上部のHPバーで自分・相手の残りHPを確認できます。

### 決着
- 相手のHPが0以下になった時点でそのプレイヤーの勝利です。

## 2. UIの見方

| エリア | 説明 |
|---|---|
| **相手/自分メインフィールド** | 現在ターン中に使用されたメインカードが一瞬表示される場所。使用後は自動的に墓地へ送られます。 |
| **相手/自分サブフィールド** | 場に出ているサブカードが並ぶ場所。カードにビーコンが付いている場合はカード下部に丸いアイコンで表示されます。「空き」は未使用の枠です。 |
| **手札エリア（画面下部）** | 自分が保有しているカードの一覧。クリック／ドラッグでフィールドや墓地に移動させて使用・破棄します。 |
| **山札表示** | 残り山札の枚数が表示されます。 |
| **HPバー** | 緑→黄→赤のグラデーションで残りHPの割合を表示します。数値表示もあります。 |
| **ログウィンドウ** | これまでの行動・ダメージ・効果発動などの履歴が時系列で流れます。「undefined」や「NaN」等が出た場合は不具合の可能性があるため報告推奨です。 |
| **行動ヒント（ログ上部の説明文）** | 現在のターンで何ができるか（サブは何枚でも出せる、メインを出すとターン終了、捨て札の残り枚数など）が表示されます。 |
| **ターン終了ボタン** | メインを使わずにターンを終える場合に押します。メインを使うと自動的にターンが終了するため、通常はサブだけ出して様子見したい時に使用します。 |
| **合成スペース（シンセサイズデッキ限定）** | メインカード2枚とサブ素材1枚を置くスペース。詳細は3章参照。 |
| **コインスペース（コインデッキ限定）** | 獲得したコインを使って回復・強化・購入ができるスペース。詳細は3章参照。 |

カードにマウスを重ねる（ホバーする）と、効果テキストの詳細説明がツールチップで表示されます。

## 3. デッキの種類と説明

このゲームには8種類のデッキがあります（うち「セレクト」「ランダム」は自由構築系で固有のデッキ効果を持ちません）。

### ① スタンダード
> 攻守ともに安定してバランスの取れたデッキ。初心者から上級者まで幅広く使える。

**デッキ効果**：最大HP +5000

素直な火力・回復・妨害がまんべんなく揃っており、初めてのプレイに最適です。

### ② ナンバー
> 旧漢数字で戦う高速サイクルデッキ。墓地・山札を操り何度も強力な数字カードを使い回す。

**デッキ効果**：捨て札が1ターン2枚まで（他デッキは1枚まで）

「壱」～「拾」などの数字カード群を軸に、山札から直接手札に加えたり、墓地から回収したりして同じ強力カードを何度も使い回すのが持ち味です。捨て札上限が緩いため、手札の入れ替えも高速に行えます。

### ③ キング
> 永続サブカード「王」を中心に守りながら戦う重量級デッキ。サブフィールド上限が6枚に拡張される。

**デッキ効果**：サブフィールド上限 6枚（他デッキは3枚）

サブフィールドを多く使う布陣型のデッキです。防御札や継続ダメージ札を並べて盤面を制圧し、「王」を中心とした耐久戦を得意とします。

### ④ トリック
> 大半のカードにランダム要素を持つ博打デッキ。サイコロを投げることができる。

**デッキ効果**：サイコロが使える（1ターン1回・全6回まで）

乱数ダメージや確率効果のカードが多く、ハイリスク・ハイリターンな駆け引きが楽しめます。サイコロ演出でその場のランダム性を直接操作するカードも存在します。

### ⑤ シンセサイズ
> サブフィールド隣の合成スペースにメイン2枚を置くと1枚の合成カードになるデッキ。

**デッキ効果**：合成スペース（メイン最大2枚＋サブ素材1枚）

固有の「合成スペース」を使い、メインカード2枚（＋任意でサブ素材1枚）を組み合わせて1枚の強力な合成カードを作り出します。サブ素材を入れると「素材効果」が追加で発動します。合成カードを使用すると分解されて元のカードとして墓地に戻ります。詳しくは5章のコンボ解説を参照してください。

### ⑥ コイン
> 与えたダメージ100につきコイン1枚を獲得。コインスペースで回復・強化・カード購入ができるデッキ。

**デッキ効果**：コインスペース（ダメージでコイン獲得、回復・強化・購入）

与えたダメージ量に応じてコインを稼ぎ、そのコインをコインスペースで消費して自己回復・ダメージ強化・カードの購入（ショップ）を行う経済型デッキです。試合が長引くほど雪だるま式に強化されていきます。

### ⑦ ビーコン
> 山札から引いたカードは30%の確率でビーコン（トラブル含む）が1つ付与される。自身や相手のカードにビーコンを付与して戦うデッキ。

**デッキ効果**：山札から引いたカードは30%の確率でビーコンが1つ付与される

カードに「ビーコン」という追加効果アイコンを付け外ししながら戦う特殊デッキです。ビーコンには自分を強化する**ノーマル系**（🟢）と、相手を妨害する**トラブル系**（🔴）、そして極めて強力な**特殊系**（🟡）があります。ビーコンの一覧は4-2章を参照してください。

### ⑧ セレクト／ランダム
> セレクトは好きなカードを30枚自分で選んで組む自由構築デッキ（☆3は8枚まで、☆2は13枚まで）。ランダムは実装済みカードから30枚を自動でランダム構築します。いずれもデッキ固有効果はありません。

## 5. コンボ・立ち回りアドバイス

### スタンダードデッキ
- **「似」＋高火力メイン**：「似」（サブ）は次に出すメインカードの効果を再発動させます。「騎」や「闇」のような大ダメージメインカードの直前に「似」を置いておくと、1ターンで2回分のダメージを叩き出せます。
- **「陣」＋連続ヒット系**：「陣」はダメージを与えるたびに追加150ダメージを乗せる継続サブです。「蛇」「爆」のような多段ヒットカードや、複数体制のサブと組み合わせると総ダメージが跳ね上がります。
- **「竜」→「樹」**：「竜」で卵を出し、「鳥」で早期処理も可能。「樹」でサブフィールドを「木」で埋めれば盤面圧力を維持しつつ、隙あらば「快」で毒処理＋大回復と繋げられます。

### ナンバーデッキ
- 「壱」で数字カードをまとめて手札に加え、山札を圧縮しながら強力な数字カード（例：拾に近いカード）を連続して展開するのが基本ムーブです。捨て札上限が2枚と緩いため、不要牌をどんどん入れ替えて理想の手札に近づけましょう。

### キングデッキ
- 「王」を早期に展開し、サブフィールド上限6枚を活かして防御札・継続ダメージ札を並べる持久戦が得意です。相手の攻めを凌ぎながらじわじわ削るプレイを意識しましょう。

### トリックデッキ
- サイコロは1ターン1回・全6回までしか使えない貴重リソースです。乱数ダメージ系カードで「最大値が欲しい」局面までサイコロ使用を温存するのがセオリーです。

### シンセサイズデッキ
- **合成の基本**：合成スペースにメインカードを2枚置くと自動で1枚の合成カードになります。さらにサブ素材を1枚添えると「素材効果」が追加発動します。合成カードは使用後、分解されて元の2枚のカードとして墓地に戻るため、実質1回の合成で2枚分のカードを消費して1回だけ強力な効果を使うイメージです。
- **「釘」＋回復・ドロー系素材**：「釘」を合成に使うと、その合成カードの素材効果が2回発動するようになります。「氷」（240ダメージ＋自身240回復の素材効果）のような素材と組み合わせると、回復量やドロー枚数が実質2倍になります。
- 素材候補は先に確保してからメイン2枚を投入すると、AIや自分の操作ミスで素材を使い損ねずに済みます。

### コインデッキ
- 与えたダメージ100につきコイン1枚を獲得できます。序盤は火力カードでコインを稼ぎ、コインスペースでの強化・回復にコインを回すことで、中盤以降のダメージ効率を雪だるま式に伸ばせます。
- ショップに強力なカードが並んだら早めに購入し、手札の質を底上げしておくと終盤が安定します。

### ビーコンデッキ
- **「鳳」＋高火力／連続ヒットカード**：「鳳」は手札のカード（☆3優先）に「ブースト」ビーコンを付与します。ブーストが付いたカードは、そのカードが与える全てのダメージ（ビーコン由来含む）が常に2倍になるため、「亜」（手札ビーコン数×400ダメージ）や「轟」（380ダメージ×3）のような高火力・多段カードに付けると爆発力が跳ね上がります。
- **「電」＋「脳」**：「電」で相手からのトラブルビーコン付与を2ターン防ぎつつ、「脳」で継続ダメージ＋トラブル付与を狙うと、自分だけが一方的にトラブルを撒く展開を作れます。
- **「変」の仕込み**：「変」をサブに置いた状態で強力なメインカード（「亜」「雅」「麤」など）を出すと、「変」がそのカードに変身して墓地へ送られます。以後山札から引く「変」は全て変身先のカードとして扱われるため、実質的に強力カードの複製枚数を増やすことができます（ただし変身先を選べないため、変身させたいタイミングを見極めることが重要です）。
- **「雅」→「和」の継続圧**：「雅」は1500ダメージに加え、ノーマルビーコン3つ付きの「和」を自動召喚します。「和」は3ターンの間、毎ターン500ダメージ＋手札全体へのビーコン付与を行うため、実質的に追加の継続火力兼サポートになります。
- **「麤」→「鹿」の物量戦**：「麤」で最大7枚の「鹿」を獲得できます。「鹿」は手札に複数あると同時にまとめて使用され合計ダメージになるため、手札を「鹿」で埋めてから一気に叩きつけると大ダメージが期待できます。
- **「混」の使いどころ**：「混」は手札のビーコンを全て別のビーコンに入れ替えます。自分の手札にトラブルビーコンが多く付いてしまった時のリセット手段として使えますが、ノーマルや特殊ビーコンも巻き込んで入れ替わるためタイミングに注意しましょう。
- **「亜」の運用**：「亜」は常にノーマルビーコン3つを保持し続ける特殊なカードです。手札の他のカードにビーコンを増やせば増やすほど「亜」のダメージも伸びるため、ビーコンを多く付与するカード（鳳・雅・和など）と好相性です。

### 汎用アドバイス
- サブカードは「出してすぐ効果が出るもの（衝撃・治療系）」と「継続することで真価を発揮するもの（追従・リジェネ系）」があるので、盤面状況に応じて優先順位を変えましょう。
- 相手のHPが残りわずかな時は、防御札（盾・護・鏡など）に妨害されない「確定ダメージ」を優先すると取りこぼしを防げます。
- 手札が捨て札上限を超えて溢れそうな時は、無駄なカードを早めに墓地へドロップして手札を回転させましょう。
